Database Kolaborasi Real-time

Sinkronkan timeline antar anggota tim secara langsung

Cara Kerja Sinkronisasi Bersama:

Aplikasi ini mendukung database cloud Supabase (PostgreSQL Real-time). Setelah dihubungkan, setiap kali Anda atau anggota tim memperbarui status, tanggal, atau tugas, layar seluruh tim akan otomatis terupdate secara langsung tanpa perlu refresh!
Dapat dilihat di menu: Project Settings → API
Gunakan public anon key (bukan service role key)
Skrip Pembuatan Tabel Database (SQL):

Jalankan di Supabase → SQL Editor sekali saja sebelum menghubungkan:

CREATE TABLE IF NOT EXISTS pbnu_timeline_tasks (
  id TEXT PRIMARY KEY,
  track TEXT NOT NULL,
  title TEXT NOT NULL,
  result TEXT,
  pic TEXT,
  start INT NOT NULL CHECK (start >= 1 AND start <= 31),
  end_day INT NOT NULL CHECK (end_day >= 1 AND end_day <= 31),
  status TEXT NOT NULL DEFAULT 'Belum',
  note TEXT,
  is_layoff_gate BOOLEAN DEFAULT FALSE,
  order_idx INT DEFAULT 0,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
ALTER PUBLICATION supabase_realtime ADD TABLE pbnu_timeline_tasks;
ALTER TABLE pbnu_timeline_tasks ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public full access" ON pbnu_timeline_tasks FOR ALL USING (true) WITH CHECK (true);
